# Habit Tracker

A **simple and interactive** habit tracker built with **React.js**. This app allows you to **track your habits**, **earn points**, and **visualize your progress** with **interactive charts**. It's a fun way to build better habits and stay motivated.

---

## Features

✨ **Track Your Habits**: 
- Add, edit, and delete habits.
- Mark habits as completed for each day, track streaks, and earn points.

📊 **Analytics**: 
- View habit trends over time with **interactive charts**.

💯 **Points System**: 
- Earn points for each successful habit check-in.

🖼️ **Motivational Quotes**:
- Get a random quote every time you check in a habit.

⚙️ **Settings**:
- Personalize your experience with dark/light theme toggle.

---

## Technologies Used

- **React.js**: Main framework for building the user interface.
- **react-router-dom**: For navigating between different pages like Dashboard, Analytics, and Settings.
- **react-hook-form**: For managing forms (e.g., adding and editing habits).
- **chart.js** & **react-chartjs-2**: For visualizing habit progress with charts.
- **LocalStorage**: To persist habits and points even after a page refresh.
